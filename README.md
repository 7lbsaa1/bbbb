# 🌌 sky7 - شبكة تواصل اجتماعي للمصورين

**sky7** هي منصة تواصل اجتماعي حديثة مبنية خصيصاً للمصورين ومحبي الصور. تتميز المنصة بتصميم زجاجي عصري (Glassmorphism)، وتعتمد على تقنيات الويب الأساسية (HTML, CSS, JS) مع قاعدة بيانات حية من **Firebase**.

## ✨ المميزات الرئيسية
- 🎨 **تصميم زجاجي (Glassmorphism):** واجهة مستخدم عصرية وجذابة تدعم الوضع المظلم.
- 🔐 **المصادقة (Authentication):** تسجيل دخول وإنشاء حساب (مع دعم التوثيق بعلامة زرقاء).
- 📸 **نشر الصور:** رفع الصور وعرضها في "Feed" تفاعلي.
- 💬 **التفاعل الحي:** إعجابات، تعليقات لحظية (Realtime).
- 🔖 **نظام المفضلة:** حفظ المنشورات للرجوع إليها لاحقاً.
- 👥 **نظام الأصدقاء:** استكشاف المستخدمين وإرسال طلبات صداقة.
- 💬 **المحادثات العائمة:** نظام شات مصغر داخل الصفحة (Floating Chat).
- 🔔 **الإشعارات:** تنبيهات حية بالإعجابات والتعليقات الجديدة.
- 🛡️ **لوحة تحكم (Admin Panel):** لإدارة المستخدمين (توثيق/حظر) والمنشورات (حذف).

## 📂 هيكل المشروع النهائي

تأكد من أن ملفات مشروعك مرتبة بهذا الشكل لضمان عمل الروابط والمسارات بشكل صحيح:

```text
sky7-project/
│
├── index.html           # صفحة الدخول والتسجيل
├── home.html            # الصفحة الرئيسية (المنشورات)
├── favorite.html        # صفحة الصور المحفوظة
├── users.html           # صفحة استكشاف الأصدقاء
├── admin.html           # لوحة تحكم الإدارة
├── README.md            # هذا الملف
│
├── css/
│   ├── global.css       # المتغيرات والتنسيقات العامة
│   ├── auth.css         # تنسيقات صفحة الدخول
│   ├── home.css         # تنسيقات الواجهة الرئيسية
│   ├── responsive.css   # التجاوب مع الهواتف والتابلت
│   └── chat.css         # تنسيقات المحادثات العائمة
│
└── js/
    ├── firebase.js      # إعدادات واتصال فايربيس (كلمات المرور/المفاتيح)
    ├── auth.js          # منطق تسجيل الدخول والتسجيل
    ├── posts.js         # جلب، رفع، والتفاعل مع المنشورات
    ├── comments.js      # نظام التعليقات الحية
    ├── favorites.js     # نظام حفظ الصور
    ├── users.js         # استكشاف المستخدمين وإضافة الأصدقاء
    ├── chat.js          # نظام المحادثات العائمة
    ├── notifications.js # الإشعارات الحية
    ├── admin.js         # منطق لوحة تحكم المدير
    └── navigation.js    # التعامل مع النافبار وتنشيط الروابط
